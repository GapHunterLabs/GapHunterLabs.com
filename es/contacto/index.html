Contacto

Ponte en contacto

Pregunta por una auditoría o un trabajo de ingeniería, reporta un problema con un plugin o señala una brecha que valga la pena investigar. Los mensajes salen por correo o como un issue de GitHub.

Reporte de seguridadReporta un problema de seguridad o una vulnerabilidad.

Iniciar un encargo

Describe el problema o el trabajo. En 2 días hábiles te respondo por escrito con el alcance, la fecha de entrega y el precio, antes de empezar cualquier trabajo.

No hace falta un pitch. Basta con describir el problema.

¿Prefieres el correo? Escribe a contact@gaphunterlabs.com

Volver al inicio

Para un encargo, incluye

  • El plugin, el repositorio o el sistema, con un enlace si es público
  • Versiones: IDE, plataforma, lenguaje o framework
  • Lo que ves: el síntoma, el error o el reporte
  • Lo que ya probaste
  • Cualquier fecha límite

Qué pasa después

Respondo personalmente por correo. Antes de empezar cualquier trabajo, te envío por escrito el alcance, la fecha de entrega y el precio, y nada empieza sin tu acuerdo. No tengo número de teléfono, ni formulario con backend, ni un tiempo de respuesta publicado.

Si vas a reportar un problema con un plugin

Incluye lo necesario para reproducirlo:

  • Nombre y versión del plugin (Settings → Plugins)
  • Nombre y versión del IDE
  • Qué esperabas y qué pasó en cambio
  • Pasos para reproducirlo, en un proyecto nuevo o no
  • Stack trace o fragmento de log que se pueda compartir
