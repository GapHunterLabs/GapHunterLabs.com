JSON Path Builder Companion

Gratis

JSON Schema Tooling

A tool window with a JSONPath field and a sample-JSON text area: type an expression, type or paste sample JSON, and every matched node is highlighted live as you type, with a real match count.

GratisPrecio

La brecha que resuelve

Building a JSONPath expression today usually means trial-and-error against an external website (pasting JSON into a browser tab, copying the expression back) or guessing blind in code and re-running until it works. Neither is available offline, and neither shows the match highlighted directly against your own sample data as you type.
